# 🏠 AG Interiors

A modern and responsive interior design website that showcases stylish home décor and furniture collections. The project focuses on delivering an attractive user interface with smooth navigation and a user-friendly experience across all devices.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and clean UI
- Interactive navigation
- Furniture and interior design showcase
- Contact section
- Smooth scrolling and user-friendly layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap
- MySQL (for backend database integration, if applicable)

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Afsu03/AG_Interiors.git
```

2. Navigate to the project folder

```bash
cd AG_Interiors
```

3. Open `index.html` in your browser.
